# analykit

A reusable analytics service.

## Supported providers

At the moment only the following providers are supported:

- Firebase Analytics

## Installation

#### From pub.dev

Add this to your `pubspec.yaml`

```yaml
dependencies:
  analykit: ^1.0.0
```

#### Or, From Git repo

```yaml
dependencies:
  analykit:
    git:
      url: https://github.com/Ragibn5/dart-flutter-packages.git
      path: analykit
      ref: analykit-1.0.0
```
