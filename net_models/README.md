# net_models

Networking models for typed API error/response handling.

## Installation

#### From pub.dev

Add this to your `pubspec.yaml`

```yaml
dependencies:
  net_models: ^1.0.0
```

#### Or, From Git repo

```yaml
dependencies:
  net_models:
    git:
      url: https://github.com/Ragibn5/dart-flutter-packages.git
      path: net_models
      ref: net_models-1.0.0
```
